## 常见问题解答

**GreenCloud 的托管方案中是否包含 Windows 许可证？**
是的。Windows Server 2022 的许可已包含在列出的每月价格中。你只需支付方案价格，并通过 RDP 或浏览器控制台进行连接。

**“不限流量带宽”具体是什么意思？**
官方规格中没有流量上限或超额费用；实际限制是端口速度（托管方案中为 1Gbps）。这指的是不计流量，而不是保证持续 1Gbps 的速度 —— 合理使用规则在任何主机商那里都适用。

**我以后可以升级吗？**
可以。RAM 和磁盘均可扩展，因此从 Managed Basic 开始并在业务增长后扩展是一种可行的方案，不必一开始就为 Business 方案支付 130 美元/月。

**如果我不满意可以退款吗？**
新客户可以在 7 天内取消第一台 VPS。特殊折扣方案被排除在外，且该保证不适用于后续的服务器或现有客户。

**开通需要多长时间？**
根据官方文档，通常在 15 分钟内，最长 2 小时。账单详情不准确可能会触发一次性的反欺诈验证，从而增加时间。
